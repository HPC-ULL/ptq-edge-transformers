# Glossary: Spanish data values kept verbatim

The code, the result files and some documents contain Spanish strings that are **data values** (labels written into CSV/JSON/report files, or compared by the code). They were deliberately **not translated**, so that every result file stays byte-identical in its values to the study's record and the code keeps producing and reading the same values. Messages (log lines, CLI help), comments, docstrings and documents were translated to English.

Each entry gives the Spanish value, its English meaning, and where it appears.

## 4. Notes

- The verdict and label strings also appear inside the translated documents (tables and quotes). They are left in Spanish there for the same reason, with the English meaning given in this glossary or in the surrounding text.
- `results/diagnostics/*/report.txt` are outputs of the scripts at the time of the measurement; their text is mostly English and only the verdict strings above are Spanish.
